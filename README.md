# Envo Desk

CRM и мониторинг продаж билетов Envo: учёт заказов из CRM Яндекс.Афиши, закупка и
себестоимость, письма и ответы клиентам, ценовые ступени, розничные цены поставщиков и
лента новостей рынка — без внешнего ассистента в операционном цикле.

Ядро — Python на виртуалке, база — Postgres, интерфейс — приложение для Mac.

## Разработка

```bash
python3 -m pytest -q                       # без базы: пропустит тесты ингеста
ENVO_TEST_DSN=postgresql://envo:envo@127.0.0.1/envo_test python3 -m pytest -q
```

Тесты не ходят в сеть: CRM отвечает подставными данными. Ингест проверяется против
настоящего Postgres — каждый тест в своей схеме, которая сносится после прогона.

Секреты в репозиторий не попадают — см. `.env.example`, на сервере `/etc/envo/env` с
правами 600.
