# Envo Desk

Mac-приложение для мониторинга продаж билетов Envo: учёт заказов из CRM Яндекс.Афиши,
вэлком-письма, догон брошенных корзин, ценовые лестницы, сводки в Telegram и расчёт цен
перепродажи — без участия внешнего ассистента в операционном цикле.

Статус: проектирование.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — архитектура, модель данных, план миграции
  с Cowork-рутин по фазам.
